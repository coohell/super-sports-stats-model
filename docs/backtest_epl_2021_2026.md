# EPL 배당 백테스트 (2021-22 ~ 2025-26)

**결론: 지금 모델은 bet365 를 이길 엣지가 없습니다.** 모델은 시장 배당보다 덜 정확하고, 모델이 고른 +EV 배팅은 전부 마감 배당보다 나쁜 가격(CLV 음수)이었습니다. 조합으로 묶으면 손실이 더 커집니다.

## 데이터와 방법

- 데이터: football-data.co.uk 의 EPL 결과와 배당을 정리해 둔 GitHub 미러 [AnishKhetani/premier-league-data](https://github.com/AnishKhetani/premier-league-data) (football-data.co.uk 는 이 개발 환경에서 막혀 있음). `python -m sssm fetch-history` 로 `data/history/E0_<시즌>.csv` 에 받습니다. 원 데이터 권리가 football-data.co.uk 에 있어 저장소에는 넣지 않았습니다.
- 검증: 미러의 2021-25 결과 1,520경기가 저장소 내장 결과와 스코어까지 100% 일치했습니다.
- 모델: Dixon-Coles, 매주 그 주 이전 경기만으로 재학습(walk-forward, 2015-16 시즌부터 학습 데이터 사용).
- 배팅 가격: bet365 시가(`B365H` 등). football-data 는 이 값을 경기 며칠 전(주말 경기는 금요일, 주중 경기는 화요일)에 수집합니다. 실제로 그 시점에 걸 수 있었던 가격에 가깝습니다.
- CLV(P): Pinnacle 마감 배당(마진 제거) 공정확률 × 건 배당 − 1. CLV(B): bet365 마감 배당 기준. 장기적으로 이기는 배터는 CLV 가 양수입니다.
- 2026년 1월 이후 경기는 Pinnacle 배당이 비어 있어 Pinnacle 을 쓰는 전략은 그 구간에 배팅하지 않았습니다.
- 재현: `python -m sssm fetch-history && python -m sssm backtest --start 2021-08-01`

## 해석

1. **모델은 시장보다 못합니다.** 1X2 에서 모델의 로그 손실(0.975)은 bet365 시가(0.951)와 차이가 큽니다. bet365 시가는 Pinnacle 시가(0.951)와 사실상 같은 정확도입니다. 즉 bet365 EPL 가격은 "느슨한" 가격이 아닙니다.
2. **모델이 시장과 다르게 보는 곳은 모델이 틀린 곳입니다.** 모델 근거로 고른 배팅은 마감까지 배당이 반대로 움직였습니다(CLV −5~−7%). 공정확률에 모델을 20% 섞는 현재 기본값(`sharp_weight=0.8`)은 수익이 아니라 잡음을 더합니다.
3. **조합은 해법이 아닙니다.** 각 폴의 CLV 가 음수라 조합 CLV 는 곱으로 더 나빠집니다(−8~−16%). 주간 최강 2폴의 +37.6% 는 80건 중 10건 적중의 운이며 95% 구간이 [−67%, +142%] 입니다. "전체 2폴" 은 같은 폴이 여러 조합에 겹쳐 구간이 실제보다 좁게 나옵니다.
4. **남은 가능성은 bet365 가 Pinnacle 보다 늦게 움직이는 순간뿐입니다.** Pinnacle 공정확률만 쓰고 bet365 가 그보다 높은 배당을 줄 때 걸면 CLV 가 +0.6% 였습니다. 다만 5시즌에 93건(시즌당 약 19건)이고, bet365 가 이기는 계정을 제한하는 현실까지 고려하면 확인된 엣지라고 할 수 없습니다. 이 방향은 경기 직전 실시간 배당(API-Football)을 모아 CLV 를 계속 기록해야 판단할 수 있습니다.
